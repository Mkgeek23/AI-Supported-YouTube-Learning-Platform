In this task, you'll set up Docker locally according to the deployment plan in [../Planning/deploy.md](file://AIinDevOps/Planning/deploy.md).

## **Task**

1. Review the `Dockerfile`, `.dockerignore`, `docker-compose.yml`, and `DockerBuildAndRun.sh` files.  
2. Create an `.env` file with the `NEBIUS_API_KEY`.  
3. Run the [DockerBuildAndRun.sh](file://AIinDevOps/DockerLocally/DockerBuildAndRun.sh) script in PyCharm. Check that everything works as expected on your local machine.

<div class="hint">
  Do not forget to copy file `.env` to the folder DockerLocally.
</div>
