## **Key components**

### **Core functions**

* `gen_prompt()`: Generates prompts for quiz creation.  
* `get_quiz()`: Creates individual quizzes.  
* `generate_all_module_quizzes()`: Orchestrates quiz generation for multiple modules.  
* `main()`: Entry point for the application.

### **The `CourseDesignerAgent` Class**

An intelligent agent responsible for:

* Generating quiz questions through `generate_quiz_questions()`  
* Handling edge cases with `_create_fallback_question()`
